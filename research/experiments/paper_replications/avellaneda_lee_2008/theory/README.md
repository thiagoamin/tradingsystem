# Avellaneda--Lee (2008) -- Theory

Source paper and replication specifications. The implementation that consumes
these specs lives in [`../one_day/`](../one_day/README.md).

| File | Role |
|---|---|
| `ssrn-1153505.pdf` | Source paper: Avellaneda \& Lee, *Statistical Arbitrage in the U.S. Equities Market*, SSRN 1153505 (2008). |
| `replication_plan.tex` / `.pdf` | The exact daily-frequency replication specification implemented under `../one_day/`. Defines universe construction, factor decomposition, OU residual model, eligibility filter, s-score, threshold rules, and the no-lookahead protocol. |
| `residual_trend_extension.tex` / `.pdf` | Extension document: residual mean-reversion vs. residual trend regime-switching. The implementation in `../one_day/hybrid_residual_*.py` is closer to this spec than to the pure replication. |

The `.aux`, `.fdb_latexmk`, `.fls`, `.log`, `.out`, and `.synctex.gz` files are
LaTeX build artifacts kept alongside source so the PDFs are reproducible
without re-running the full BibTeX chain. They can be regenerated by
`latexmk -pdf <file>.tex` if lost.
